# PlaylistMaker 🎵

**PlaylistMaker** is an application that allows users to search for tracks in the iTunes database based on a given query.

---

## Features 📋
- 🔍 Search by track name  
- 🎤 Search by artist  
- 🎧 Preview tracks  
- 📂 Create playlists from tracks  
- 💾 Store playlists in the device's local database  
- ⭐ Add tracks to a favorites list  
- 💾 Store the favorites list in the device's local database  

---

## Implementation 🛠️
- **Design Pattern**: MVVM  
- **Architecture**: SingleActivity approach  
- **Database**: Organized using Room  
- **Networking**: Implemented with Retrofit
